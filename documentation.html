Documentation Technique & Stratégique

0. L'Objectif du Système 🎯

"Un Simulateur de Vol pour la Stratégie"

Imaginez que vous pilotez un avion complexe (votre entreprise). Vous ne voulez pas tester une nouvelle manœuvre risquée en plein vol avec de vrais passagers.

Ce système permet de :

  1. Modéliser la réalité : Créer une copie virtuelle de votre entreprise (réputation, contrats, capacités).
  2. Tester le futur : Si je change ma stratégie éthique aujourd'hui, que se passera-t-il dans 5 ans ?
  3. Voir l'invisible : Comprendre les effets secondaires (les "boucles de rétroaction").

1. La Structure des Données 🔧

Le système repose sur la Dynamique des Systèmes (Stocks & Flux).

💡 L'Analogie Plomberie : Imaginez des baignoires (Stocks) reliées par des tuyaux (Flux).

A. Les Stocks (Réservoirs) 🛢️

L'état du système à un instant T.

{
    "reputation_capital": {
        "value": 75,
        "unit": "index_0_100",
        "description": "Confiance du public"
    }
}

B. Les Flows (Tuyaux) 🚰

Ce qui fait varier les stocks (débit). Ils contiennent la logique mathématique.

{
    "reputation_decay": {
        "from": "reputation_capital",
        "to": null,
        "formula": "autonomous_lethal_capacity * backlash_coefficient"
    }
}

Fig 1. L'interface "Model Builder" permet d'ajouter ces Stocks et Flux manuellement.

2. L'IA (Ollama) : Le Copilote 🧠

L'IA agit comme un architecte qui traduit vos demandes en structure JSON.

  • Entrée : "Je veux investir dans la pub."
  • Traitement : L'IA comprend qu'il faut un Flux positif vers la Réputation.
  • Sortie : Elle écrit le JSON nécessaire (voir ci-dessus) et le moteur l'exécute.

3. Scénarios & Paramètres ⚙️

Les "Profils" sont des configurations pré-enregistrées pour simuler des stratégies types.

Fig 2. Menu de sélection des profils (Aggressive Growth, Ethical Constraint, etc.).

4. Architecture du Projet 🏗️

Le flux de données va du fichier JSON vers l'écran, piloté par le moteur Python.

Le Flux d'Interaction

  1. Lecture : Le `Moteur` lit le `Fichier JSON`.
  2. Simulation : Le moteur fait tourner le temps (Année 1...10).
  3. Affichage : L' `Interface` Streamlit affiche les courbes.
  4. Modification : L'utilisateur change un paramètre -> Le moteur recalcule instantanément.
